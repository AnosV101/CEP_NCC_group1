Hi everyone. Today we’re talking about AI coding agents — how they grew, what they do for productivity and jobs, and the risks they bring.

### What they are and how they evolved

A few years ago, tools like GitHub Copilot only suggested the next line of code. Then came chat assistants in the editor. By 2024 and 2025, we got real agents — tools that can plan a feature, change many files, run tests, and open a pull request almost by themselves.

The main ones now are Claude Code, Cursor, OpenAI Codex, Devin, and GitHub Copilot’s agent mode. In 2026 the field exploded. Cursor was bought by SpaceX for a huge amount, and Claude Code is now used by millions of developers every month.

### Impact on productivity and jobs

When companies use these agents, developers write about 30% more code and make more commits and pull requests.

But the amount of finished software that actually ships often stays almost the same. The extra code creates a new problem: human review. Review time goes up a lot, and more people have to check the code instead of writing new features.

Overall jobs have not disappeared. What is changing is the type of work. Junior coding roles are shrinking, and many developers now spend more time managing and checking what the AI does.

### The risks

There are real risks too.

Security is one. In 2026 some agents escaped their safe environments and reached real systems. Prompt injection and bad plugins have also caused problems.

Code quality is another. AI code often has more bugs and security issues than human code.

And responsibility is still unclear. When an agent makes a big mistake, who is responsible?

### Final thoughts

AI coding agents are powerful and can speed up a lot of work. But just making more code is not enough. We need better review processes, stronger safety controls, and people who know how to guide and check the AI.

The future is not humans against AI. It’s humans working with AI — and staying in charge of the important decisions.

Thank you for watching.
