# Background: AI Coding Agents

## 1. What are AI coding agents?
- AI tools that write, run, test and fix code with little human input  
**Different from autocomplete:** They can plan a task, edit multiple files and even run commands
**Example:** You say "add a login page" and the agent builds and tests it, if it fails, then it tries a different approach.
- source: [https://www.mindstudio.ai/blog/what-are-ai-coding-agents]

## 2. How we got here (timeline)
**2021:**  Github Copilot launches in preview and suggests the next line of code
**2022:**  Chat tools like ChatGPT let people ask coding questions in plain English
**2024:**  First "AI software engineer" tools appear (e.g., Devin)
**2025-2026:** Agents like Claude Code, Cursor, and Copilot's agent mode work on whole projects
-source[https://www.taskade.com/blog/ai-coding-history]

## 3. Main tools
| Tool | Made by | What it does |
|---|---|---|
| GitHub Copilot | GitHub/Microsoft | Autocomplete + agent mode in the editor |
